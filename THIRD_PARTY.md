# Study data and third-party software

The [MIT license](LICENSE) covers the original IgAN-Flow code, documentation and synthetic fixture authored for this project. It does not grant a new license to study source data or bundled metadata, and it does not replace dependency licenses.

## Study attribution

The source study is [NCBI GEO GSE285335](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE285335). Study investigators supplied the expression matrices, donor labels and metadata. The preserved GEO metadata identifies PMID 41466033. Cite the linked study separately: G. Kim et al., “Chromatin accessibility of circulating CD8⁺ T cells differentiates disease severity in IgA nephropathy,” *Scientific Reports*, vol. 16, article 1700. [Publisher article and DOI: 10.1038/s41598-025-31213-9](https://doi.org/10.1038/s41598-025-31213-9), [PubMed record](https://pubmed.ncbi.nlm.nih.gov/41466033/). Consult the accession and article for reuse information.

`research/GSE285335_series_matrix.txt.gz`, the source manifest, file list and inspection summaries preserve the public metadata retrieved on September 6, 2026. The research notebook audits those historical metadata snapshots. Runtime release verification uses current artifacts and the frozen input reference.

`assets/reference_inputs.json` contains SHA-256 digests calculated locally from all 78 downloaded files and rechecked against the retained originals. These are reproducibility references generated by this project; NCBI did not publish these checksums. The public example contains project-derived donor summaries and count exports. Raw expression downloads and AnnData files are excluded from the repository.
